## 5. Como instalar e executar

O SpiderRescue pode ser executado em um computador Windows por meio do arquivo executável disponibilizado com o projeto.

### Executando o jogo pelo arquivo .exe

1. Baixe o arquivo ZIP do projeto.
2. Extraia o conteúdo para uma pasta no computador.
3. Mantenha a pasta `assets` no mesmo diretório do executável.
4. Localize o arquivo `SpiderRescue.exe` (ou o nome real do executável).
5. Clique duas vezes no arquivo para iniciar o jogo.
6. No menu inicial, consulte os controles e inicie a partida.

**Importante:** não remova a pasta `assets`, pois ela pode conter imagens, sons e outros recursos necessários para o funcionamento do jogo.

### Executando pelo código-fonte Python

Caso o código-fonte esteja disponível, também é possível executar o jogo utilizando Python.

**Requisitos:**

- Python instalado no computador.
- Biblioteca Pygame instalada.
- Arquivos e recursos do projeto.

**Passos:**

1. Baixe e extraia o projeto.
2. Abra a pasta do projeto no terminal.
3. Instale a biblioteca Pygame, caso necessário, com o comando `pip install pygame`.
4. Execute o arquivo principal utilizando `python main.py`.

Após a execução, a janela do jogo deverá ser aberta.

## 6. O que desenvolvi e aprendi

O desenvolvimento do SpiderRescue foi uma oportunidade de colocar em prática os conteúdos estudados na disciplina de Linguagem de Programação Aplicada.

Durante a elaboração do projeto, trabalhei com conceitos fundamentais de programação, organização de código e desenvolvimento de jogos digitais.

Entre os principais conhecimentos aplicados e desenvolvidos, destacam-se:

- **Programação em Python:** utilização de variáveis, estruturas condicionais, laços de repetição e funções.
- **Desenvolvimento de jogos 2D:** criação de uma aplicação com interface gráfica e interação com o jogador.
- **Controle de personagem:** implementação de comandos para movimentação e ações.
- **Lógica de programação:** criação das regras, desafios e condições de vitória e derrota.
- **Organização do projeto:** separação e gerenciamento dos arquivos de código e recursos utilizados.
- **Testes e correções:** identificação de erros e realização de ajustes para melhorar o funcionamento.
- **Compilação:** compreensão do processo de transformação de um projeto Python em um executável para Windows.


O SpiderRescue permitiu compreender melhor como os conceitos de programação podem ser utilizados na criação de uma aplicação interativa.

Além de ampliar meus conhecimentos em Python, o desenvolvimento do jogo contribuiu para melhorar minhas habilidades de resolução de problemas, raciocínio lógico, criatividade e organização.

O resultado representa a aplicação prática dos conhecimentos adquiridos durante a disciplina, desde a estruturação do projeto até a preparação do jogo para execução.
